# VotoRadar QA

Test automation portfolio for [VotoRadar](https://votoradar.y4tress.com).

> 🚧 Work in progress

## Planned scope

- Test plan (scope, out of scope, risks)
- Manual test cases in Markdown
- End-to-end tests with Playwright + TypeScript (Page Object Model)
- Bug reports tracked in GitHub Issues
- CI with GitHub Actions
- API tests and a basic performance scenario
